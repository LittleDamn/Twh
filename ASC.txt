# ====================== TWH 设备码对照表 ASC.txt ======================
# 设备码(6位) = 厂商码(1) + 浏览器码(1) + 型号码(2) + 序号(2)
# 例：AC01X7 = Apple / Chrome / iPhone系列 / 序号X7
# 供 index.html 生成设备码、UNPWD.html 解密还原设备信息
# 等号分隔；# 开头为注释；段落标题仅供阅读
#
